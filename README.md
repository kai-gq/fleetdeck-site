# FleetDeck 官网(fleetdeck-site)

FleetDeck 官方网站:单页静态站,GitHub Pages 发布。

- **线上地址**:https://kai-gq.github.io/fleetdeck-site/
- **页面**:`index.html`(零外部依赖:无 CDN、无网络字体,离线可直接打开)
- **资源**:`assets/`(界面截图 + 运行时图标,站内全部相对路径引用)
- **更新方式**:改 `index.html` / `assets` 后直接 push 到 `main`,Pages 自动重新发布
- **源草稿**:在开发仓的 `FleetDeck官网/` 目录同步维护(改完复制到本仓库)

产品仓库:https://github.com/kai-gq/FleetDeck
